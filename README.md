# Academica

A responsive online education landing page built with HTML, CSS, and Bootstrap 5.

🔗 **Live Demo:** [https://jannat-miftahul.github.io/Academica/](https://jannat-miftahul.github.io/Academica/)

---

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1

## Sections

- Navbar
- Hero
- Featured Courses
- Course Categories
- Featured Instructors
- Testimonials
- CTA
- Footer

## Getting Started

Clone the repo and open `index.html` in your browser — no build step needed.
